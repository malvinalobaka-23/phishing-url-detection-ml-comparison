# A Comparative Study of Machine Learning Methods for Phishing URL Detection: Implications for Cybersecurity Risk Management

## Project Overview

This research was undertaken as part of the MSc Business Analytics programme at the University of Greenwich.

The study compares four supervised machine learning methods for phishing URL detection and examines how their predictive performance and feature importance can inform organisational cybersecurity risk management.

## Research Questions

**RQ1:** How can the comparative performance of machine learning methods for phishing URL detection inform organisational cybersecurity risk management?

**RQ2:** How do URL-based features contribute to the detection of phishing URLs, and what do their relative importance suggest about phishing-related cybersecurity risks in data collected between November 2024 and September 2025?

## Dataset

The research uses the URL-Phish dataset obtained from Mendeley Data.

The cleaned analytical dataset comprises:

- Total observations: 115,217
- Legitimate URLs: 98,634 (85.61%)
- Phishing URLs: 16,583 (14.39%)
- Final numerical predictors: 17
- Target variable: label
- Machine learning task: Binary classification

The analysis focuses exclusively on lexical and structural URL characteristics.

## Machine Learning Models

Four supervised classification algorithms were evaluated:

- Logistic Regression
- Decision Tree
- Random Forest
- Linear Support Vector Machine (SVM)

## Research Methodology

The study adopts a quantitative, deductive and comparative experimental research design.

The analytical workflow includes:

1. Exploratory data analysis and data quality assessment.
2. Data cleaning and feature selection.
3. Stratified training, validation and testing partitions (70%, 15% and 15%).
4. Feature standardisation for Logistic Regression and Linear SVM.
5. Class imbalance management using balanced class weights.
6. Model training and comparative performance evaluation.
7. Feature importance and signed coefficient analysis.
8. Final evaluation using the held-out test dataset.
9. Interpretation of cybersecurity risk management implications.

## Evaluation Metrics

Model performance was assessed using:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Average precision
- Confusion matrices

## Key Findings

Random Forest demonstrated the strongest overall predictive performance, particularly in terms of F1-score, ROC-AUC and average precision.

Logistic Regression and Linear SVM demonstrated higher phishing detection recall but generated more false-positive classifications.

Feature importance analysis identified URL length, entropy, domain length, digit ratio and HTTPS usage as influential predictors across the selected models.

## Cybersecurity Risk Management Implications

The findings highlight the importance of balancing phishing detection effectiveness against the operational consequences of classification errors.

False negatives may expose organisations to undetected phishing threats, while false positives may increase investigation workloads and disrupt legitimate activities.

Model selection should therefore consider organisational risk tolerance, operational requirements and the relative consequences of classification errors rather than relying exclusively on accuracy.

## Methodological Limitations

- Reliance on a single secondary dataset.
- Potential overlap of related URLs or domains across data partitions.
- Absence of external dataset validation.
- Limited hyperparameter and classification threshold optimisation.
- Feature importance represents predictive associations rather than causal relationships.

The findings do not establish effectiveness in a live organisational environment.

## Reproducibility

A fixed random seed of 42 was used to support experimental reproducibility.

To reproduce the analysis:

1. Download the Jupyter Notebook and requirements.txt from this repository.
2. Obtain the original URL-Phish dataset from Mendeley Data.
3. Place Dataset.csv in the same directory as the Jupyter Notebook.
4. Install the required Python libraries using:

   `pip install -r requirements.txt`

5. Open the Jupyter Notebook and execute the cells sequentially.

The original dataset is not included in this repository. The notebook contains the experimental outputs, visualisations and analytical findings.
